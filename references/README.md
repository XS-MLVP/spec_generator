# 参考资料

本目录保存经过筛选的优秀文档和验证计划案例，用于改进本项目的内容组织、表达方式和验证方法。

参考资料不是 XiangShan 实现证据，不能替代 Chisel/Scala 源码、指定配置的 elaborated RTL 或 `evidence/`。使用时应提炼可迁移原则，不直接复制参考资料中的模块结构、信号、测试计划或结论。

| 文件 | 来源 / 用途 |
| --- | --- |
| `coverage_cookbook.pdf` | Verification Academy Coverage Cookbook（2013-08-21 快照，版权声明见 PDF）；参考 Coverage Examples(Practice) 中关于观察点、有效采样、分箱、交叉、命名和覆盖闭合的表达方法。 |

引入新的外部资料前必须确认许可和再分发条件，并记录来源、版本或获取日期。参考资料只能用于方法提炼；不得大段复制原文、图表或示例代码到模板和生成文档。
