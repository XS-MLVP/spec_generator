# 中文 DV 文档格式

当前模板的正式输出顺序固定为：

1. 文档摘要
2. 设计概览
3. 功能行为
4. 验证策略与 Testplan
5. 形式化属性契约
6. Sign-off 与开放项
7. 附录 A：I/O 定义与接口约束
8. 附录 B：参数、编码、状态与复位
9. 附录 C：范围、文档控制、证据与版本变更
10. 附录 D：CK 追溯矩阵
11. 附录 E：场景视角 Test Case

正文按读者理解 DUT 的顺序组织：职责与边界 -> 事务模型 -> 数据/控制通路 -> 时序与状态 -> 验证策略。正文使用逻辑接口名；完整扁平 RTL 端口、Scala 路径、参数清单和证据索引放附录。一个事实只在一个位置完整定义，其他章节引用其 ID 或章节。

每个功能行为段落至少说明激励条件、处理过程、输出或状态结果、时延/顺序和边界条件。接口存在 ready/valid 时，明确 transaction 接受条件、backpressure 和 payload 保持。存在 flush、replay、cancel、错误或配置裁剪时，明确存活事务、取消事务、优先级和 disabled 无副作用。

模板中的 HTML 注释是生成约束，不应出现在正式正文中。禁止输出生成过程说明、阅读建议、排版说明或无法证实的“设计意图”断言。
